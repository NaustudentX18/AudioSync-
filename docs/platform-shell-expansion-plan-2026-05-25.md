# Platform Shell Expansion Plan (Phase 6.6)

## Objective
Expand AudioSync beyond core web shell while preserving PWA-first reliability.

## Tracks
1. Car surface integration
   - Media metadata robustness
   - seek/play/pause action reliability
   - large-touch controls profile

2. Wearable companion scope
   - now-playing controls
   - bookmark quick action
   - queue next item action

3. Widget shell
   - home-screen now-playing status
   - quick resume + smart rewind

## Guardrails
- Keep web PWA primary path
- No regression on offline playback
- No secrets in client bundles

## Exit criteria
- Compatibility matrix documented
- smoke tests for media controls
- roadmap/TODO updated with done evidence per sub-track
