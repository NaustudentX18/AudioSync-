# AudioSync — Screenshot Design Specification

**Resolution**: 1440px wide (provide 2x versions when possible)
**Theme**: Dark (#0a0a0f) with amber (#f0a000) + cyan (#00d4ff) accents
**Typography**: Inter or system sans-serif
**Style**: Premium, clean, slightly angled shots preferred

## Required Screenshots

| Filename              | View                        | Key Elements to Capture                     | Priority |
|-----------------------|-----------------------------|---------------------------------------------|----------|
| `library.png`         | Library grid                | Book covers, search, "Add Book" button      | High     |
| `player.png`          | Open player                 | Waveform, progress, voice name, controls    | High     |
| `voices.png`          | Voice selection modal       | 6-8 voice cards with quality badges         | High     |
| `intelligence.png`    | Gemini panel open           | Summary + detected chapters                 | Medium   |
| `settings.png`        | Settings view               | API key field, offline toggle, PWA status   | Medium   |

**General Rules**:
- Consistent window/device frame across all shots
- Show hover states where relevant
- Keep text readable
- Use the same book for continuity across screenshots

**Save in**: `assets/` folder
