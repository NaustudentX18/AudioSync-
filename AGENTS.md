# AudioSync — Agent Swarm Rules

> This file is injected into every agent session (Claude Code, Hermes, Codex).
> Read it before claiming any task. Update `TODO.md` when you start and finish work.

---

## Core Principles
- **One task at a time.** Claim, complete, update TODO.md — then move on.
- **Never edit the same file simultaneously.** Coordinate via TODO.md.
- **Visual work** (banner, screenshots, demo) can run in parallel with code work.
- **Bring-your-own API keys** — never commit or log keys. Stored in `localStorage` only.
- **Local-first by default** — Kokoro TTS runs 100% offline. Gemini/OpenAI are optional fallbacks.

---

## Workflow
1. **Read `TODO.md`** — pick an unchecked task from the current phase.
2. **Claim it** — edit `TODO.md` to add your agent name + `IN PROGRESS`.
3. **Do the work.** Keep your scope limited to one file/task per session.
4. **Update `TODO.md`** — mark `[x]`, add notes or blockers.
5. **Commit early, commit often.** Small, focused commits.

## Important Configuration

### API Keys
AudioSync uses **bring-your-own API keys** — never hardcode, never commit.
- **Gemini** (AI Intelligence): `VITE_GEMINI_API_KEY` env var or manual input in settings
- **OpenAI TTS** (optional cloud TTS): manual entry in settings
- **Kokoro TTS** — bundled model weights, 100% offline

Keys are stored only in browser `localStorage`. Never log, print, or persist them to disk.

### Build Targets
- `npm run dev` — Vite dev server on `http://localhost:5173`
- `npm run build` — Production build → `dist/` (includes PWA service worker)
- `npm run preview` — Serve `dist/` locally for testing
- `npm run build && npm run preview` — Full production preview

### PWA
- Manifest: `public/manifest.json`
- Service worker: `dist/sw.js` (generated by vite-plugin-pwa)
- Workbox precache: 5 entries, ~2.5 MB total
- Cache limit bumped to 5 MB for `ort-wasm-simd-threaded.jsep` (21 MB)

## Coding Conventions
- **TypeScript** strict mode, no `any` without justification
- **Tailwind CSS** utility-first, no custom CSS files (use `@apply` in `index.css`)
- **Component style** — functional components + hooks, no class components
- **State** — Zustand for global state, `useState`/`useReducer` for local
- **Imports** — React imports first, then third-party, then local (`@/lib/*`)
- **File naming** — `kebab-case` for files, `PascalCase` for React components
- **Line length** — 100 chars max

---

## Git Conventions
- **Branch naming**: `feat/`, `fix/`, `chore/`, `docs/`, `refactor/`
- **Commit format**: `feat: add chapter navigation` or `fix: tts audio buffer leak`
- **No force pushes to `main`**
